# LaTeX Templates Index — Scenariu 2: Cumpărare apartament

Empty-field LaTeX mirrors of each form PDF in this folder. Each `.tex` recreates the visual layout of the corresponding PDF with all input fields blank, ready to be auto-filled with citizen data by the Primării AI Coach app.

| File | Description |
|------|-------------|
| `ITL-001-Declaratie-impozit-cladiri-PF.tex` | Declarație fiscală pentru stabilirea impozitului/taxei pe clădirile rezidențiale/nerezidențiale/cu destinație mixtă aflate în proprietatea persoanelor fizice (formular național ITL-001, Model 2016, Anexa nr. 1 OMFP). Conține secțiunile I–VII: identificare contribuabil (până la 3 coproprietari), împuternicit, adresa de reziden\c{t}ă, date clădire rezidențială cu tabel tipuri A–F și dotări, date clădire nerezidențială, scop mixt, declarație document anexe, semnături. |
| `Anexa-1-Cerere-eliberare-CI.tex` | Cerere pentru eliberarea actului de identitate (Anexa Nr. 1, S.P.C.E.P.) — formular tabelar cu CNP pe casete, date personale, domiciliu actual/anterior, stare civilă, copii minori, motiv eliberare, plus pagina 2 cu blocul „NU SE COMPLETEAZA DE SOLICITANT" (consimțământ titular spațiu, primit cerere, preluat imaginea, verificat, actualizat, eliberat CI/CIP). |
| `Anexa-5-Declaratie-gazduitor.tex` | Anexa Nr. 5 — Declarație găzduitor: proprietarul locuinței declară că primește în spațiul său de locuit o persoană care își schimbă domiciliul la acea adresă. Folosit pentru CI cu domiciliu la rude (Primăria Cluj-Napoca). |
| `700.001-Cerere-abonament-parcare-strada-PF.tex` | Cerere abonament parcare stradală (Cod 700.001), Direcția Parcări Publice Cluj-Napoca, persoane fizice — date solicitant, autoturism (nr. înmatriculare, serie șasiu), checkbox-uri pentru documente justificative și comunicare prin e-mail. |
| `Consimtamant-OUG-41-2016.tex` | Consimțământ OUG nr. 41/2016 art. 2¹ alin. (2) — autorizează Primăria Cluj-Napoca să solicite copii ale documentelor emise de alte instituții publice în vederea soluționării cererii. |
